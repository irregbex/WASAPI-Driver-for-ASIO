2. mingw-w64 GCC runtime (x64 and x86 DLLs, WasapiDriverDiag.exe,
   WasapiDriverTest.exe)
------------------------------------------------------------------
Toolchain: mingw-w64 GCC 13 ("win32" thread model), linked with -static
-static-libgcc -static-libstdc++.
- libstdc++ and libgcc (GCC runtime libraries): STATICALLY linked. Copyright
  Free Software Foundation, Inc. License: GNU GPL version 3 with the GCC
  Runtime Library Exception, version 3.1. The exception allows the
  resulting binaries to be distributed under terms of our choice; we
  distribute them under the GPL anyway.
- mingw-w64 CRT startup and support code: STATICALLY linked. Copyright the
  mingw-w64 project contributors. License: mostly public domain, with some
  files under the Zope Public License 2.1 or permissive MIT/BSD-style
  licenses, as stated in the mingw-w64 COPYING file. No winpthreads library
  is linked (win32 thread model).
- Microsoft C runtime (msvcrt.dll): DYNAMICALLY linked; it is part of
  Windows and is not distributed with this program.
- Windows system DLLs (kernel32, user32, gdi32, advapi32, ole32, shell32,
  avrt, winmm): DYNAMICALLY linked operating system components, not
  distributed.
- dbghelp.dll (Windows): loaded at runtime from System32 with LoadLibraryEx
  only when the crash handler is installed (0.7.0); not linked, not
  distributed.

4. Windows API headers
----------------------
The program is compiled against the Windows API headers and import
libraries shipped with mingw-w64 (and with Zig), not against the Microsoft
Windows SDK. Those headers are in the public domain or under the
permissive licenses listed in the mingw-w64 COPYING file. Interface
definitions such as WASAPI, MMDevice, WIC and DWM are Windows APIs; Windows
and WASAPI are trademarks of Microsoft (see TRADEMARKS.txt).
0.9.8: the TraceLogging (ETW) event encoder (src/tlg.h) is this project's own
code, written from Microsoft's public documentation of the TraceLogging
event format; no Microsoft source code is included. Microsoft's
TraceLoggingDynamic.h (MIT License) was evaluated and is not used. The ETW
functions are imported from advapi32.dll (a Windows system DLL, section 2).
The Windows Performance Recorder profile (trace/WasapiDriver.wprp) is this
project's own file; it names the Windows provider Microsoft-Windows-Audio
only by its public name and GUID.
