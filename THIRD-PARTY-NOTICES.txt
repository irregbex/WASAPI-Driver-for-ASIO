4. Windows API headers
----------------------
The program is compiled against the Windows API headers and import
libraries shipped with mingw-w64 (and with Zig), not against the Microsoft
Windows SDK. Those headers are in the public domain or under the
permissive licenses listed in the mingw-w64 COPYING file. Interface
definitions such as WASAPI, MMDevice, WIC and DWM are Windows APIs; Windows
and WASAPI are trademarks of Microsoft (see TRADEMARKS.txt).
0.9.8: the TraceLogging (ETW) event encoder (src/tlg.h) is this project's own
code, written from Microsoft's public documentation of the TraceLogging
event format; no Microsoft source code is included. Microsoft's
TraceLoggingDynamic.h (MIT License) was evaluated and is not used. The ETW
functions are imported from advapi32.dll (a Windows system DLL, section 2).
The Windows Performance Recorder profile (trace/WasapiDriver.wprp) is this
project's own file; it names the Windows provider Microsoft-Windows-Audio
only by its public name and GUID.

6. SoX Resampler library (soxr) 0.1.3 (all driver DLLs, 0.9.10)
-----------------------------------------------------------------
The driver's fixed-ratio sample-rate converter (used when the DAW rate
differs from the device rate, e.g. a 44.1 kHz project on a 48 kHz device)
can use the SoX Resampler library "libsoxr" 0.1.3 ("soxr HQ"; selected in
the panel, Rate conversion = soxr; the default engine is the program's own
sinc). It is compiled from source and STATICALLY linked into
WasapiDriver64.dll, WasapiDriver32.dll, WasapiDriverARM64.dll and
WasapiDriverARM64X.dll; no soxr DLL is used or distributed. The tools
(WasapiDriverDiag.exe, WasapiDriverTest.exe) do not contain it.
Copyright: (c) 2007-18 robs@users.sourceforge.net (Rob Sykes) and the soxr
contributors (third_party/soxr/AUTHORS). Official home:
https://sourceforge.net/projects/soxr/
License: GNU Lesser General Public License, version 2.1 or (at your option)
any later version (LGPL-2.1-or-later). The full text of the LGPL 2.1 is the
appendix at the end of this file (also third_party/soxr/COPYING.LGPL);
soxr's own licence note is third_party/soxr/LICENCE.
How to obtain the source: the complete source of the library as used, with
the exact upstream version (tag 0.1.3, commit 945b592b), the list of files
with their SHA-256 and the build configuration, is the folder
third_party/soxr of this program's source code (README-vendored.txt there),
published with every release ("Source code" and
WASAPI-Driver-for-ASIO-<version>-src.zip on the Releases page). Only the
files needed for the plain C constant-rate engine are included, unchanged;
three small files of this project configure and wrap it (soxr-config.h,
fifo-headroom.c, data-io-portable.c; LGPL-2.1-or-later like the library).
Relinking (LGPL 2.1 section 6): the whole program is free software under the
GPL with its complete source code, so you can rebuild the driver DLLs with a
modified version of soxr (BUILDING.txt), which is what the LGPL requires
for a program that links the library statically.
